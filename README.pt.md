<h1 align="center"><img src="https://github.com/KrishBharadwaj5678/image-processing/raw/main/assets/icons/ImageProcessing.png" width="35"/> Processamento de Imagens</h1>

<p align="center">
  Uma ferramenta de detecção de cores baseada em OpenCV que utiliza o espaço de cores HSV e técnicas de mascaramento para identificar e destacar cores específicas em imagens.
</p>

## <img src="https://github.com/KrishBharadwaj5678/image-processing/raw/main/assets/readme/features.gif" width="35"/> Funcionalidades

| Funcionalidade | Descrição |
| -------------- | --------- |
| 🎨 Detecção de Cores | Detecta cores específicas em uma imagem |
| 🔍 Processamento HSV | Converte imagens para HSV para uma detecção de cores mais precisa |
| 🎯 Máscara de Cores | Isola as cores selecionadas usando máscaras personalizadas |
| 🖼️ Destaque de Imagens | Destaca as regiões onde a cor selecionada foi detectada |
| 💻 Processamento de Imagens | Demonstra conceitos fundamentais de visão computacional |

## <img src="https://github.com/KrishBharadwaj5678/image-processing/raw/main/assets/readme/gettingStarted.gif" width="35"/> Como Começar

### 1️⃣ Clonar o Repositório

```bash
git clone https://github.com/KrishBharadwaj5678/image-processing.git
````

### 2️⃣ Acessar o Diretório do Projeto

```bash
cd image-processing
```

### 3️⃣ Criar um Ambiente Virtual

```bash
python -m venv venv
```

### 4️⃣ Ativar o Ambiente Virtual

- Windows

```bash
venv\Scripts\activate
```

- macOS/Linux

```bash
source venv/bin/activate
```

### 5️⃣ Instalar as Dependências

```bash
pip install -r requirements.txt
```

### 6️⃣ Executar o Projeto

```bash
python app.py
```
