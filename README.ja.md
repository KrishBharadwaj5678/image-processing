<h1 align="center"><img src="https://github.com/KrishBharadwaj5678/image-processing/raw/main/assets/icons/ImageProcessing.png" width="35"/> 画像処理</h1>

<p align="center">
  OpenCVをベースにした色検出ツールです。HSV色空間とマスキング技術を使用して、画像内の特定の色を検出・強調表示します。
</p>

## <img src="https://github.com/KrishBharadwaj5678/image-processing/raw/main/assets/readme/features.gif" width="35"/> 機能

| 機能 | 説明 |
| ---- | ---- |
| 🎨 色検出 | 画像内の特定の色を検出します |
| 🔍 HSV色処理 | 正確な色検出のために画像をHSVに変換します |
| 🎯 カラーマスキング | カスタマイズ可能なマスクを使用して選択した色を分離します |
| 🖼️ 画像の強調表示 | 検出された色の領域を画像上で強調表示します |
| 💻 画像処理 | コンピュータビジョンの基本的な技術を実践します |

## <img src="https://github.com/KrishBharadwaj5678/image-processing/raw/main/assets/readme/gettingStarted.gif" width="35"/> はじめに

### 1️⃣ リポジトリをクローン

```bash
git clone https://github.com/KrishBharadwaj5678/image-processing.git
````

### 2️⃣ プロジェクトディレクトリへ移動

```bash
cd image-processing
```

### 3️⃣ 仮想環境を作成

```bash
python -m venv venv
```

### 4️⃣ 仮想環境を有効化

- Windows

```bash
venv\Scripts\activate
```

- macOS/Linux

```bash
source venv/bin/activate
```

### 5️⃣ 依存関係をインストール

```bash
pip install -r requirements.txt
```

### 6️⃣ プロジェクトを実行

```bash
python app.py
```
