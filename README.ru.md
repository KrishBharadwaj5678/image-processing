<h1 align="center"><img src="https://github.com/KrishBharadwaj5678/image-processing/raw/main/assets/icons/ImageProcessing.png" width="35"/> Обработка изображений</h1>

<p align="center">
  Инструмент обнаружения цветов на основе OpenCV, использующий цветовое пространство HSV и методы маскирования для определения и выделения определённых цветов на изображениях.
</p>

## <img src="https://github.com/KrishBharadwaj5678/image-processing/raw/main/assets/readme/features.gif" width="35"/> Возможности

| Возможность                 | Описание                                                    |
| --------------------------- | ----------------------------------------------------------- |
| 🎨 Обнаружение цветов       | Определяет определённые цвета на изображении                |
| 🔍 Обработка HSV            | Преобразует изображения в HSV для точного определения цветов |
| 🎯 Маскирование цветов      | Изолирует выбранные цвета с помощью настраиваемых масок     |
| 🖼️ Выделение областей       | Выделяет области изображения с обнаруженным цветом          |
| 💻 Обработка изображений    | Демонстрирует основные методы компьютерного зрения         |

## <img src="https://github.com/KrishBharadwaj5678/image-processing/raw/main/assets/readme/gettingStarted.gif" width="35"/> Начало работы

### 1️⃣ Клонирование репозитория

```bash
git clone https://github.com/KrishBharadwaj5678/image-processing.git
````

### 2️⃣ Переход в директорию проекта

```bash
cd image-processing
```

### 3️⃣ Создание виртуального окружения

```bash
python -m venv venv
```

### 4️⃣ Активация виртуального окружения

- Windows

```bash
venv\Scripts\activate
```

- macOS/Linux

```bash
source venv/bin/activate
```

### 5️⃣ Установка зависимостей

```bash
pip install -r requirements.txt
```

### 6️⃣ Запуск проекта

```bash
python app.py
```
