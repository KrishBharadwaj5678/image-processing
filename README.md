<h1 align="center"><img src="https://github.com/KrishBharadwaj5678/image-processing/raw/main/assets/icons/ImageProcessing.png" width="35"/> Image Processing</h1>

<p align="center">
  An OpenCV based color detection tool that uses HSV color space and masking techniques to identify and highlight specific colors in images.
</p>

## <img src="https://github.com/KrishBharadwaj5678/image-processing/raw/main/assets/readme/features.gif" width="35"/> Features

| Feature                     | Description                                               |
| --------------------------- | --------------------------------------------------------- |
| 🎨 Color Detection          | Detects specific colors within an image                   |
| 🔍 HSV Color Processing     | Converts images to HSV for accurate color detection       |
| 🎯 Color Masking            | Isolates selected colors using customized masks           |
| 🖼️ Image Highlighting       | Highlights detected color regions in the image            |
| 💻 Image Processing         | Demonstrates fundamental computer vision techniques       |

## <img src="https://github.com/KrishBharadwaj5678/image-processing/raw/main/assets/readme/gettingStarted.gif" width="35"/> Getting Started

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/KrishBharadwaj5678/image-processing.git
```

### 2️⃣ Navigate to the Project

```bash
cd image-processing
```

### 3️⃣ Create a Virtual Environment

```bash
python -m venv venv
```

### 4️⃣ Activate the Virtual Environment

- Windows

```bash
venv\Scripts\activate
```

- macOS/Linux

```bash
source venv/bin/activate
```

### 5️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

### 6️⃣ Run the Project

```bash
python app.py
```
